# Unicode allowlist for scripts/check_invisible_unicode.py
#
# This file pins legitimate exceptions to the invisible/bidi Unicode gate.
# Format (one entry per line):
#
#     <path-glob> <U+XXXX> # written reason (mandatory)
#
#   * <path-glob> is matched against the repo-relative path with fnmatch
#     (e.g. "test/fixtures/unicode/*" or "docs/foo.md").
#   * <U+XXXX> is the specific allowed code point in hex.
#   * Everything after "#" is the mandatory human reason. An entry without a
#     reason is rejected as a configuration error.
#
# Blank lines and lines starting with "#" are comments.

# The scanner's own negative-test fixtures deliberately embed forbidden
# characters so the unit tests can prove the gate fires. They must never be
# treated as a real violation by the repo-wide gate.
