Self-hosted portfolio analytics, early MVP.

Ledger-first portfolio insight without execution rails.

Portfolixir helps self-hosters and portfolio tinkerers model investment history, inspect read-only reports, and keep financial logic explicit.

Repository Quick start Product docs

Product overview

Portfolixir is built for transparent, reproducible portfolio analysis with clear boundaries: self-hosted by default, ledger-driven history, and read-first interfaces for reports and future API/AI integrations.

It is inspired by Portfolio Performance workflows, but is independent and not affiliated with or endorsed by Portfolio Performance.

MVP workflow

  1. Maintain portfolio, account, transaction, security, and classification data.
  2. Review imported documents and factsheets before relying on derived facts.
  3. Inspect read-only views for positions, payments, allocations, and valuation snapshots.
  4. Use authenticated read APIs and read-only MCP boundaries for controlled integrations.

Current MVP surface

  • Ledger-based portfolio model with positions, balances, and valuation snapshots.
  • Securities and classification workbench flows with taxonomy and mapping support.
  • Import/document intake and review paths for controlled data ingestion.
  • Read API boundary for analytics and future read-only AI/API integrations.

Safety and non-goals

  • No financial, legal, tax, or investment advice.
  • No broker, banking, trading, payment, order, or rebalance execution.
  • No write-capable external trading or banking integrations.
  • No production-readiness promise for the current MVP.
