Early-stage portfolio workspace (read-first, safety-scoped).

Project status

Portfolixir is in active roadmap development. The repository currently focuses on data models, reporting workflows, and controlled read-oriented interfaces.

Current feature focus

  • Securities and classification workbench flows
  • Valuation, payments, and import review/reporting features
  • Structured implementation and review workflow with test gates

Safety and non-goals

  • No broker/order/payment execution capability
  • No write-capable external trading or banking integrations
  • No real financial data fixtures in tests
