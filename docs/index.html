Self-hosted portfolio data hub with a ledger-first core.

Why Portfolixir?

Portfolixir is built for transparent, reproducible portfolio analysis with clear boundaries: self-hosted by default, ledger-driven history, and read-first interfaces.

It is inspired by Portfolio Performance workflows, but is not affiliated with Portfolio Performance.

Current features

  • Ledger-based portfolio model with positions, balances, and valuation snapshots
  • Securities and classification workbench flows with taxonomy and mapping support
  • Import/document intake and review paths for controlled data ingestion
  • Read API boundary for analytics and future read-only AI/API integrations

Roadmap

  • Harden reports for valuation, payments, trades, and classification exposure
  • Expand safe Portfolio Performance-style import/reimport and conflict handling
  • Advance a strict read-only MCP/API layer after authenticated read boundaries

Safety and non-goals

  • No broker/order/payment execution capability
  • No write-capable external trading or banking integrations
  • No financial advice and no real financial data fixtures in tests
