# Portfolixir Logo Assets

Official logo direction: **Round Flask** with violet, teal green, and coral red chart-like liquid layers.

- `logo.svg` — default compact UI mark
- `logo-mark.svg` — explicit mark-only asset
- `logo-wordmark.svg` — adaptive full wordmark
- `logo-light.svg` — fixed light-background wordmark
- `logo-dark.svg` — fixed dark-background wordmark
- `logo-app-icon.svg` — rounded app icon base

The SVGs intentionally draw liquid layers first and the flask outline last, so chart separators do not cut into the glass rim.
