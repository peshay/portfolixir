# Domain Glossary

## Portfolio

A container for holdings and transactions. It has a base currency, for example EUR.

## Security

A tradable instrument such as a stock or ETF. It has a symbol, optional exchange, optional ISIN and
trading currency.

## Category

A user-defined classification item, for example `Core ETF`, `Dividend`, `Tech`, `Europe`,
`Satellite`, or `Crypto`. Categories belong to a taxonomy and may have a description.

## Taxonomy

A group of categories. Examples: `Asset Class`, `Region`, `Strategy`, `Risk Bucket`, `Custom Depot
Categories`.

## Buy transaction

A recorded purchase of a quantity of a security for a gross amount, fees, taxes and currency.

## Position

The derived current holding of a security in a portfolio, calculated from transaction history.

## Quote

A market price for a security from a provider at a specific time.

## Symbol candidate

A provider-specific possible match for a user-entered symbol. Example: searching `AAPL` may return
`AAPL`, `AAPL.F`, `AAPL.SG`.

## Valuation

The calculated value of positions using latest quotes and FX rates, reported in portfolio base
currency.
