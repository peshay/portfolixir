# Repository metadata and social preview

This file documents the intended GitHub-facing metadata state for Portfolixir.

## Target repository description

`Self-hosted portfolio analytics and wealth graph platform built with Elixir, Phoenix, and LiveView
(early-stage).`

## Target topics

- `elixir`
- `phoenix`
- `liveview`
- `portfolio`
- `wealth-management`
- `fintech`
- `self-hosted`

## Social preview image

Current reusable asset in the repository:

- `priv/static/images/logo-wordmark.svg`

Preferred social preview asset for GitHub UI:

- raster image, 1280×640 (or same 2:1 ratio), PNG
- proposed path: `docs/assets/social-preview-portfolixir.png`

At the moment, this card documents the gap and target format. A dedicated follow-up can add a
finalized PNG asset.

## Manual GitHub UI follow-ups

These settings cannot be fully applied from repository files alone and must be updated in GitHub
repository settings:

1. **General → Description**: set to the target description above.
2. **General → Topics**: set/update to the target topic list above.
3. **General → Social preview**: upload the final preview PNG once available.

## Scope note

This is repository-surface documentation only. It does not change Phoenix runtime behavior or domain
logic.
