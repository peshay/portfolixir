## Scope

The Realized gains facet renders one number in a year × month matrix. The closed round-trips it aggregates are computed by `Ledger.TradeMatcher`, exposed on the API and shown per security on the Securities → Trades tab — but no surface lists them across the portfolio, which is what the facet's name promises and what the owner named on 2026-08-15 as the Portfolio Performance "Trades" comparison (per position: buy → sell, holding period, result). Target: the facet opens with three figures (realised total, hit rate, average holding period), the trades list (security, buy → sell, holding period, quantity, cost, proceeds, result abs and %), and the matrix as a "Realisiert je Periode" disclosure. Subtitle and basis line per #787.

**Needs a decision** (review Part 5, Q2): the 2026-08-15 triage deferred filing a Trades view until it was reconciled with this facet so one table is built once. This issue is that reconciliation — the facet *is* the Trades view. Leaving the issue as filed signs it; a comment moves the list to a Securities-area surface instead.
