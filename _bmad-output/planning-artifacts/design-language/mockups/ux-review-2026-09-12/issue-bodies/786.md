## Scope

The history table prints price and quantity as raw decimals — `42.1`, `60000`, `0.05` — through `format_decimal/1` (`transaction_management_live.ex:604`) while the month headers next to them read `1.263,00 EUR` through `Format.money`. And the default column set (`@tx_column_defaults`, `:62`) has no amount: a dividend row shows "50" (the quantity) and no money. Fix: the locale-aware formatter with tabular numerals and right alignment for every numeric cell, and the gross amount (signed by kind, with currency) in the default column set — the column picker keeps it toggleable.
