## Scope

A held position whose last quote is five weeks old shows "42,64 · +2,03 %" in the securities list with nothing to say the price is old; only the "Kurs veraltet" filter chip and the Overview count know. The spine's State Patterns → *Stale data* row (attention tone **and** glyph **and** the word, never hue alone) has no implementation at the three places a price is read. This story adds the marker to the securities list row (price cell: glyph, "veraltet", the quote date on the line under the price), the securities detail header, and the Wealth holdings valuation — and adds the `:clock` glyph to the icon set for the freshness note (the list row uses `:alert_triangle`, the attention severity's glyph). The threshold is the existing `DataQuality.stale_days()`; the basis is `max(updated_at)` per security as the spine records.
