Board 01 ⑧ made the sentence name the Portfolio Performance file instead of a CSV column, but kept its claim: „Gebucht ist der Bruttowert … Die Differenz sind die Gebühren und Steuern der Zeile.“ Since ADR-0053 A6 the section also lists a JSON or a converter row whose tax refund was counted twice (A1). ① The sentence — true for a gross value and for a refund counted twice Transaktionen → Import → Vorschau, „Bereits importiert, mit anderem Betrag“

The file is a Portfolio Performance JSON export of a sale of 10 Arbolia Inc. with a fee of 5,00 and a tax refund of 25,00 (a negative tax unit). The instance imported it before A1: the sale's cash 120,00 (PP's amount, which already holds the refund) beside the refund 25,00 split off it, so Test-Cash holds 25,00 too much. The correction takes the refund out of the sale: +120,00 → +95,00, its price 12,50 → 10,00. Nothing in that line is a gross value, and the fee of 5,00 is not in the difference.

Heute — JSON file, refund counted twice

Heute — „Gebucht ist der Bruttowert … Gebühren und Steuern“

The sentence explains a difference that is not there. It tells the operator the 25,00 are the row's fees and taxes; the row's fee is 5,00 and it has no positive tax. An operator who checks the file against the sentence finds it wrong and has no reason left to trust the figures beside it.

  • What was booked is named by its cause, not by one format: „wie eine frühere Version des Imports ihre Zeile las“, then both readings the correction can meet — a CSV row's gross value (§1: Betrag before Gesamtpreis) or a cash amount that also held the refund booked beside it (A1: JSON amount, a converter's Betrag).

④ The columns — „Gebucht · Korrigiert · Differenz“ the table of „Bereits importiert, mit anderem Betrag“ (α closing act, second fix round: UAT-4)

The same JSON sale as ①. The file states the sale's cash as 120,00 (PP's amount, the refund inside it); the correction books the sale 95,00, the cash less the refund 25,00 booked beside it (A1). The middle column, „Laut Datei“, shows +95,00 — a figure the file does not hold. For a PP CSV row whose gross value was booked, the column happens to equal the Gesamtpreis, which is why the word held on board 09; for every A1 correction it is false. The column shows what the correction writes, so it is named for that: „Korrigiert“ / „Corrected“. „Gebucht“ and „Differenz“ stay. The figures, signs and colours do not change.
