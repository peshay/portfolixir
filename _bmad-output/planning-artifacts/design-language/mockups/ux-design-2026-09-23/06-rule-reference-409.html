Vorher / Nachher — keine Variantenwahl. Im Batch entdeckt (Lane A3, ADR-0049 §8): Ein Wertpapier, eine Kategorie oder eine View, die eine Regel liest, kann nicht gelöscht werden. Das Nein existierte schon; neu ist, dass es die Regel beim Namen nennt, statt „Transaktionen oder Kurshistorie“ zu behaupten. Alle Namen sind erfunden.

Wertpapier löschen — der Dialog nennt die Regel Vorher / Nachher

Vorher behauptet der Dialog jeden Verweis als Buchung oder Kurs — auch wenn es eine Regel ist, die das Wertpapier misst. Nachher nennt er die Regeln. Der Ausweg „Stattdessen stilllegen“ bleibt: Eine Regel, die gegolten hat, behält ihren Bezug als Teil ihrer Geschichte, darum verschwindet das Wertpapier nicht, es wird stillgelegt. Nur eine Regel, die nie gegolten hat, lässt sich löschen und gibt den Bezug frei.
