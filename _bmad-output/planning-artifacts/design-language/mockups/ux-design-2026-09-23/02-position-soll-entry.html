Variante A — Positionen aufklappbar in derselben Tabelle empfohlen

Jede Kategorie mit zugeordneten Wertpapieren bekommt „Positionen“ zum Aufklappen (offen, sobald eine Position ein Ziel trägt). Die Positionszeilen sind Eingaben im selben Formular, also ein Speichern, eine Summe, ein Journaleintrag je Zeile. Sobald eine Position ein Ziel hat, wird das Kategoriefeld zur gestrichelten Anzeige „Σ Positionen“ — die Rechenregel aus ADR-0030 §2 wird sichtbar statt erklärt. Leere Positionsfelder bedeuten „kein Positionsziel“, nicht null.

Variante B — ein Dialog je Kategorie Tabelle bleibt flach

Die Tabelle bleibt wie heute; ein Knopf „Positionen gewichten…“ öffnet je Kategorie einen nativen Dialog. Hält die Übersicht kurz. Der Preis: Das Speichern im Dialog und das Speichern des Plans sind zwei Schreibvorgänge mit zwei Zuständen, die Summe im Hauptformular stimmt erst nach dem Schließen, und man sieht nie alle Positionsziele gleichzeitig — genau die Pivot-Sicht, für die #481 geschrieben wurde.
