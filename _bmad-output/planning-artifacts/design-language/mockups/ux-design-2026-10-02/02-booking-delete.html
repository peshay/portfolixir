Was Löschen heute tut (Ledger.delete_transaction/2)

  • Eine Zeile, in einer Datenbanktransaktion, mit einem Journaleintrag (delete, transaction), der die ganze Zeile als Vorher-Bild hält. Das Journal lesen nur API und MCP (GET /api/v1/journal); nichts in der Oberfläche schreibt eine Buchung daraus zurück.
  • Alles Abgeleitete folgt beim nächsten Lesen: Bestände, Kontostände, Rendite, Trades und realisierte Gewinne, Snapshot-Vergleiche (ein Snapshot ist eine Marke, keine Kopie). Eine Umbuchung oder Wertpapierumbuchung ist eine Zeile; beide Seiten entfallen.
  • Der Inhalts-Hash geht mit. Eine importierte Buchung trägt import_hash; gelöscht, wird er nicht stillgelegt (das tut nur eine Zusammenführung, ADR‑0050 §3). Ein erneuter Import derselben Datei bucht sie wieder.
  • Ein Split: nur diese Zeile. Die Zeile des anderen Portfolios bleibt — und mit ihr das Split-Ereignis, nach dem das Diagramm die Kurse bereinigt (Quotes.split_events/1 fasst die Zeilen zusammen). „Split erfassen“ lehnt ein anderes Verhältnis am selben Tag ab, solange eine Zeile steht.

Was API und MCP ablehnen — fast nichts

  • 404, wenn die Buchung unbekannt oder schon gelöscht ist (auch wenn sie verschwand, bevor das Löschen ihre Sperre bekam). Die Oberfläche hat dafür schon einen Satz: „Diese Transaktion existiert nicht mehr.“
  • 409 nur bei einem Changeset-Fehler; ein Löschen erzeugt heute keinen.
  • Keine Prüfung, was davon abhängt. Ein Kauf, dessen Stücke ein späterer Verkauf verbraucht hat, lässt sich löschen; der Verkauf hat danach keinen zugeordneten Kauf mehr, und der Bestand kann unter null fallen. Kein Fremdschlüssel verweist auf eine Buchung.

Die Rückfrage nennt deshalb keine Ablehnung, die es nicht gibt, und warnt vor nichts, was die API nicht auch prüft (siehe „Zweifel“ in Teil 2).

Und ihr Gegenstück auf API und MCP — heute löscht der Agent Zeile für Zeile und hat dazwischen den halben Zustand —, oder die Story begründet, warum das genügt.
  • Den Satz „Danach …“ aus Projection.effects/1 der Buchung; Split und Saldo gesetzt mit eigenem Satz.
  • Die Zeilenzahl eines Splits und die Namen seiner Portfolios für A4; ob import_hash gesetzt ist für A3 (das Feld liegt an der Zeile).
  • Den Dialog als geteiltes Bauteil auf zwei Seiten (Historie, Wertpapier), damit A8 nicht die Seite wechselt.
