2#1313 — rows already imported into another portfolio are named and held back Transaktionen → Import → Vorschau

Today. The Imports page books into the default portfolio (ADR-0024), and the import's content hash includes the portfolio. A file first imported into „Anleihen“ — by an agent over the API, or by a script — previews on the page as four new bookings, offers to create „Coupon-Cash“ and „Coupon-Depot“ a second time, and one confirm books the history twice. Decided (owner-only, the ADR-0050 amendment the plan carries): keep the per-portfolio scope; the preview reads hashes across portfolios, names rows already imported elsewhere and holds them back by default; the operator can include them deliberately. The open choice is the anatomy. Case: kupons-2026.json, four entries, all four imported into „Anleihen“ on 01.11.2026; the page books into „Hauptportfolio“.

Variante A empfohlen — one collapsed group per portfolio, held back, with an include toggle

Why A.

  • The decision is per portfolio, not per row. „This history is already in Anleihen“ is one fact about a set of rows; one sentence and one switch say it, and the switch's consequence (a second copy, in this portfolio) is stated once beside it. B asks the operator to answer the same question four times — or four hundred: a Portfolio Performance export holds the whole history, and the usual case is a file imported elsewhere in full.
  • It fits the preview's anatomy. The preview speaks in counts — the cards, „Anzahl pro Art“, „33 Buchungen bereits importiert · 2 neu“ on each mapping row, the nothing-to-import note — and has no row list. A adds one disclosure in that language; B adds the page's first row table, with a checkbox column the apply would have to honour row by row.
  • A partial copy is the error B invites. Ticking some rows of an already-imported history books a fragment of it twice; A includes the group or nothing.
  • The rows stay inspectable one tap away (the 390-px frame shows the group open), so A hides nothing B shows.
  • B fits only if the owner expects files that mix rows from several portfolios with rows that are new, and wants to pick among them.
