① H38 — the manual logo: from an image URL to an upload „Logo verwalten“ · LogoOverrideDialog.dialog/1

Today the dialog's one way to set a logo is a form „Bild-URL“ with „URL speichern“ (save_logo_url → Catalog.set_logo_override/3 → LogoStore.store_manual_override/3, which fetches the address server-side). app.css has no rule for .logo-override__form; the generic form rules stack label, field and button. After the image travels from the operator's browser over the LiveView socket (allow_upload(:logo, accept: ~w(.png .jpg .jpeg .webp), max_entries: 1)), and the server stores the bytes with store_manual_bytes/4, which already checks the type, the size and the image header. Nothing is fetched by the server for a manual logo. „Erneut suchen“ (discovery) and „Logo entfernen“ stay as they are.
