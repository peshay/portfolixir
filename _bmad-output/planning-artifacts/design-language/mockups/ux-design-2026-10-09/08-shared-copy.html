    Why A. It returns the operator to where the action started — the same answer the page's dialogs give (the delete dialog's data-focus-return, else data-focus-fallback; WCAG 2.4.3), and the one Classifications already gives a dismiss. A keyboard user who synced the prices and read the answer is on „Kurse aktualisieren“ again, one Tab from the list.

    • The trigger is known when the result is set: the LiveView sets the result in the handler of the event that produced it, so the slot can carry its trigger's id (focus_return) and a fallback (focus_fallback, the section's heading) beside the result; the dismiss focuses the first that is on the page. Classifications' dismiss_focus/1 becomes the general rule rather than a second one.
    • The fallback is a heading, not the page's top: the history's #transaction-history-heading already takes the focus after a delete (issue 912), with the house ring. A page's heading that becomes a fallback takes tabindex="-1" and the class .result-focus-fallback (rule ②); a page without a section heading (Securities) falls back to its toolbar's first control, the search field.
    • A busy line has no dismiss, and a result replaced by the next action keeps today's behaviour; only the ×'s own removal moves the focus.

    Variante B — der geleerte Ergebnis-Platz

    B — der Ring um einen leeren Platz

    B focuses the slot itself (tabindex="-1", as #securities-action-result is already focusable for #920). It is the cheapest — one target per page, no trigger to remember. Against it: the slot is empty once the note is gone, so the ring draws around nothing (with #1160 it has no height at all), and a screen reader announces an empty group; the reader is not where they were, only near it.

    Variante C — immer die Überschrift

    C — die Wertpapierliste hat keine eigene: die Überschrift der Seite

    C is predictable — the same place on every page — and matches the history after a delete. Against it: where the trigger still stands, C sends the operator away from it. The securities list has no section heading at all; its heading is the top bar's „Wertpapiere“, above the search and the chips (measured below).
