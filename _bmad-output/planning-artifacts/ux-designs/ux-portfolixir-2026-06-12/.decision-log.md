- 2026-06-12 — **Brain dump captured (verbal, no new imports):**
  - KEEP: dark/light mode (exists); accent color with the three logo-derived

  - PAIN: current UI is cluttered/unübersichtlich; experience rated poor by
    the owner. This run is experience-led, not a reskin.

    instead of today's static SVG. [NOTE FOR UX] Mechanism is constrained by

    the UX spine captures the perceived behavior).

    responsive web, three target surfaces, no native apps in this run.
  - OPEN TENSION (owner-raised): "Am I thinking too classically / too
    PP-shaped?" Visionary alternative sketched: LLM owns configuration and
    data maintenance via MCP; the human UI becomes visualization-first.
