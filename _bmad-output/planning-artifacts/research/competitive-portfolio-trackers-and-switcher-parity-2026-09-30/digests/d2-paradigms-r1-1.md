## Patterns for "mobile access without a hosted cloud"

- **A file on a drive, with no server (PP).** The desktop writes the file, a consumer cloud drive moves it, and the phone app recomputes locally. The sync experience is the drive's, not the app's (#1, #3, #7). The listing's WebDAV option (#2) is the one route where the storage could be self-operated. That is an inference: no recipe was found.
- **A local database per device, synced through the vendor (Wealthfolio).** Each device keeps its own database, and a paid relay syncs them with encryption (#8, #11–#13). The self-hosted Docker web mode is a separate path with its own auth and reverse-proxy docs (#9, #10). No evidence was found that the Wealthfolio phone app can talk to a self-hosted server.
- **A server plus an installable web app on a private network (Actual).** The phone installs the web app, which works offline (#35). The official HTTPS page names Tailscale, or Caddy with a DNS challenge, as the way to get certificates without exposing the server to the internet (#37). Actual is the only product whose official docs name a no-exposure path.
- **A server plus a PWA and a third-party native client (Ghostfolio).** The PWA is mobile-first (#22). An independent native iOS client signs in with the instance's security token and leaves network reachability to the user (#27, #29). The official docs stop at reverse-proxy trust settings (#26).
- **Exposure behind app-level auth.** Wealthfolio pairs its web mode with Argon2id/OIDC and a reverse-proxy compose file (#10). Ghostfolio documents only proxy trust (#26).
- **Third-party hosting as the no-VPN escape hatch.** Actual on PikaPods and Fly.io (#34, #36), Wealthfolio on PikaPods, Railway, ElfHosted and Hostinger (#15, #16), rotki on Railway and Hostinger (#30, #32). This is someone else's cloud, which the decision wants to avoid, but the listings show that people want it.
- **The switcher's baseline is a native app.** Every SaaS peer checked has a store app (#39–#44), and so does the switcher's current PP setup (#1).
- **None of the products found reaches a self-hosted instance from a phone without internet exposure by itself.** Actual hands the job to Tailscale or Caddy (#37), and none ships its own tunnel or relay for a self-hosted server.
