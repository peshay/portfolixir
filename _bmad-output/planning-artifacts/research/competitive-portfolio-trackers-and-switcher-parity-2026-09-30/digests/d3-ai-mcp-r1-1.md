## Patterns worth studying
- **Drafts instead of direct writes.** Wealthfolio turns agent-initiated writes into editable activity drafts and "reviewed" classification drafts behind a dedicated write scope (16, 17); Foliora advertises "agent execution of human-approved changes" (39). No peer documents a dry-run flag (10).
- **Untrusted-content rule against prompt injection.** Wealthfolio states that attachment contents and tool output are untrusted data that "cannot authorize drafts", and pins this in a versioned system prompt (16, 18).
- **Scopes plus audit rather than one all-powerful token.** Wealthfolio: scoped Personal Access Tokens, every tool call audited (15); Agni Folio: separate read and write OAuth scopes, revocable from a "Connected AI" settings page (30); Ghostfolio shipped a "Restricted view and manage" access permission during its MCP rollout (3).
- **Read-only is the default posture of hosted commercial MCPs.** Parqet (26), Fillfolio and ChainFolioAI (40); write-capable servers are first-party self-hosted (14, 2) or community (7, 31).
- **Keeping the tool list small or switchable.** The community Ghostfolio server has a read-only mode, tag-based tool groups and a `search_tools` / `call_tool` transform (9); Ghostfolio's first-party server grew one tool at a time from a single holdings tool (1, 2). No server checked documents MCP prompts or resources (10).
- **Keeping the LLM outside the app.** Ghostfolio's copy-prompt and copy-portfolio-data actions hand context to any LLM without the app calling one (4); Wealthfolio instead embeds a bring-your-own-provider assistant with per-provider data permissions (19, 21).
- **Auth and transport follow the deployment model.** Self-hosted: local tokens, stdio or HTTP, uvx or Docker (8, 15); hosted: remote Streamable HTTP with OAuth, and `mcp-remote` for stdio-only clients (25, 30, 39, 40, 41).
- **Registry presence is uneven.** The community Ghostfolio server is in the official registry (11), which is filling with hosted portfolio MCPs from AI-native entrants (39, 40, 41, 42); the first-party built-ins of Wealthfolio and Ghostfolio did not show up (43).
- **The advice boundary is mostly unaddressed in public material.** Only Wealthfolio shows an explicit safety policy (18); getquin markets advice-adjacent questions (35); the community Ghostfolio server has no disclaimer (10). Evidence here is thin.
